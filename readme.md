# Anti Leak Bedrock — Minecraft 1.21.x

This resource pack replaces the visible textures of the following blocks:

- Deepslate
- Tuff
- Bedrock
- Deepslate ores

with a netherite block texture.

## Installation

1. Put the folder into a `.zip` file, if not already done.
2. Place this `.zip` file in `.minecraft/resourcepacks`.
3. Enable the pack in **Options > Resource Packs**.
